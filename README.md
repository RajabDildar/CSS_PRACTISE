# CSS Practice Repository

A structured collection of CSS, SCSS, and Bootstrap practice files built to help learn and revisit core web styling concepts through real examples.

This repository is a hands-on learning reference for front-end styling. It contains multiple mini-projects, layout experiments, and CSS exercises that cover a wide range of topics from basic selectors and spacing to flexbox, grid, animations, transitions, pseudo-elements, and responsive design.

If you find this repository useful, consider giving it a star.

## What this repository includes

This repo is organized as a practical CSS playground with examples that demonstrate:

- Flexbox and layout alignment
- CSS Grid fundamentals and layouts
- Positioning and stacking
- Typography, spacing, colors, borders, and shadows
- Pseudo-elements and advanced selectors
- Transitions and animations
- Responsive styling patterns
- SCSS usage and structure
- Bootstrap examples and component styling
- JavaScript-free interactive UI experiments

## Repository structure

The repository is grouped by topic so it is easier to navigate and study specific CSS concepts.

- `BOOTSTRAP/`  
  Bootstrap examples, layouts, and utility-based styling patterns.

- `grids/`  
  CSS Grid examples and layout challenges.

- `pseudo-Elements/`  
  Examples using `::before`, `::after`, and other pseudo-element styling techniques.

- `scss/`  
  SCSS files demonstrating variables, nesting, reusable styles, and modular styling practices.

- `practise sets/`  
  Exercise-based practice files intended for repetition and skill building.

- `important files/`  
  Useful reference files and reusable snippets that help during learning and revision.

- `traffic light/`  
  Small UI project showing CSS styling and animation in a practical scenario.

- `level 5/`  
  More advanced experimentation and practice work.

- `extras/`  
  Additional CSS experiments, helper files, and side examples.

- `cssImages/`  
  Images used throughout the project.

- `.vscode/`  
  Editor workspace settings for local development.

## How to use this repo

1. Open the folder related to the topic you want to study.
2. Open the HTML files in a browser to see the visual result.
3. Read the matching CSS or SCSS files to understand the implementation.
4. Reuse the examples as reference material when building your own projects.

## Suggested learning flow

If you are working through CSS step by step, a good way to explore this repository is:

- Start with basic layout and styling concepts
- Move to Flexbox and Grid
- Practice pseudo-elements and transitions
- Experiment with animations
- Review SCSS and reusable styling patterns
- Use Bootstrap examples for UI structure and quick layouts

## Why this repository is useful

This repo is not just a set of random files. It is a learning archive that helps you:

- revisit core CSS concepts quickly
- compare different approaches to the same layout problem
- build confidence through repeated practice
- keep an organized reference of experiments and examples
